# Pulso repository conventions

- Preserve the separation between the general public community and the legacy verified private pilot. A public projection must not promote private data/media, expand upload permissions, or bypass human review.
- Luigi-authored Pulso posts include a generated image unless Luiz explicitly asks for text only. Political illustrations should not visually endorse a party/candidate. Follow `docs/editorial-images.md` for the current reviewed public-image association, generation provenance, private-media boundaries and verification.
- Use existing shared PostCard/public scope definitions for guest and authenticated views. Keep the same original conversation IDs when adding presentation assets.
- Never put service-role/admin credentials in public-prefixed variables or build output. Local builds can use a clearly noncredential public placeholder; production uses its configured public credential.
